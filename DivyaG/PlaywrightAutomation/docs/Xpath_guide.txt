Absolute Xpath: An absolute XPath is a complete path from the root element to 
the desired element. It starts with a single forward slash (/) and specifies 
each node in the hierarchy. For example, /html/body/div[1]/h1 would select the
 first h1 element within the first div of the body.

 e.g:/html/body/div[1]/div[1]/div/main/article/div/div[1]/div[2]/div/input

 Relative Xpath: A relative XPath is a path that starts from the current node
or context
e.g://tagname[@attribute='value]
//input[@placeholder='Enter username']
//input[@placeholder='Enter password']
//input[@id='password']
//textarea[@id='address']
//h1[@class='entry-title']
//*[@class='entry-title']

advanced xpath:

ancestor:It will help to identitify ancestor element with ref of 
grand child element
//ref_name[@attribute='value']/parent::target name[@attribute='value']
e.g://td[text()='Pune']/ancestor::tbody
e.g://td[text()='Pune']/ancestor::table[@id='cities']

parent:
target parent with reference of child element
//ref_name[@attribute='value']/parent::target name[@attribute='value']
//td[text()='Mumbai']/parent::tr
//td[text()='Pune']/parent::tr//input

preceding:Identify elements above reference element
e.g://input[@name='firstname']/preceding::input
//input[@name='firstname']/preceding::a[text()='Login Page']

preceding sibling:
////td[text()='Kolkata']/preceding-sibling::td
//td[text()='Kolkata']/preceding-sibling::td/input[@type='checkbox']

following:Identify elements below reference element
e.g://input[@name='firstname']/following::input
//input[@name='firstname']/following::input[@id='billing_name']
//input[@name='firstname']/following::a[@data-type='link']
//input[@name='firstname']/following::a[text()='Login Page']

following sibling:
//td[text()='Kolkata']/following-sibling::td
