1. Create a folder with name as "AutomationProject"
2. Open intergrated terminal in ""AutomationProject"
3. Install playwright in "AutomationProject" with below command
    -> npm init playwright@latest
    -> go with all default option continue press enter and complete the installation.
    -> wait till Happy hacking message visible on console.


4. Create a folder structure as per automation framework.
